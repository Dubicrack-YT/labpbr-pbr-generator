Capas útiles,
promesas honestas.

Sin imágenes individuales. Java acepta ZIP/JAR; Bedrock, ZIP/MCPACK. Un JAR se lee solo como fuente Java y siempre exporta un ZIP.

Sin emisión falsa. El canal emissive se deja en cero. No se generan heightmaps, AO horneado, bump ni parallax.

Compatibilidad real. Bedrock Vibrant puede aplicar PBR a bloques, ítems y entidades; RTX conserva PBR solo para bloques.

Control local. Límite de 300 MB y 20 000 texturas elegibles por archivo. Las texturas no abandonan el dispositivo.
